## Preflight Commands

Run these before mapping:

```bash
adb devices -l
mobilerun ping --device emulator-5554
```

Start app from scratch once:

```bash
adb shell am force-stop com.myswimpro.android.app
adb shell monkey -p com.myswimpro.android.app -c android.intent.category.LAUNCHER 1
```

Capture screenshot:

```bash
adb exec-out screencap -p > /Users/adi/myswimmpro-clone/manual-navigation-map/screenshots/S001_home.png
```

Capture UI state, optional but useful:

```bash
mobilerun device ui --device emulator-5554 > /Users/adi/myswimmpro-clone/manual-navigation-map/states/S001_home.txt
```

## Manual Mapping Procedure

1. Read `Current Position`.
2. Pick the first `open` item from `Branch Backlog`.
3. Navigate to its `From Screen` using the `Navigation Tree`.
4. Before clicking, confirm the action is not in `Do Not Click`.
5. Click exactly one action.
6. Wait for UI to stabilize.
7. Capture screenshot and optional UI state.
8. Add or update a row in `Screen Registry`.
9. Add the edge to `Navigation Tree`.
10. Add newly visible safe actions to `Branch Backlog`.
11. If a branch ends, mark the screen `leaf` and use Back to return to the nearest branch point.
12. Update `Current Position` after every click or Back.

## Status Values

- `open`: screen/action still needs exploration
- `mapped`: screen/action has been explored
- `leaf`: terminal safe branch
- `blocked`: cannot continue without user/environment change
- `risky_leaf`: stopped because next action is destructive, account-changing, billing, or final confirmation
